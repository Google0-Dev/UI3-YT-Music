# ⬇️ Installation

>[!NOTE]
>If you run YouTube Music as a desktop app (Progressive Web App / PWA) via your browser, this script will still work seamlessly.

Choose one of the installation methods below:

### Method 1: Tampermonkey (Recommended)
>[!IMPORTANT]
>Ensure your userscript extension has the necessary permissions enabled and is active.

This method is a one-time setup; the script will load automatically on every visit.

Open your [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) Dashboard.

Click the Create a new script tab (the + icon).

Delete any existing code in the editor and paste the full script code.

Save the file by going to File > Save (or pressing Ctrl + S / Cmd + S).

### Method 2: JavaScript Console
> [!NOTE]
> This method requires you to manually paste the code into the console every time you launch YouTube Music.

Open the Inspect Panel in your browser by pressing F12, or by right-clicking anywhere on the webpage and selecting Inspect (or Inspect Element).

Navigate to the Console tab and paste the [main.js](https://github.com/Google0-Dev/UI3-YT-Music/blob/main/main.js) code.

(You may be prompted to type "allow pasting" into the console before you can paste the code).
